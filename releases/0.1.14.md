# Vault Codex 0.1.14

The reasoning-effort selector now uses dot selection with smooth transitions and animated Fast/Ultra effects.

## Changes

- Click a reasoning-level dot to move the white thumb smoothly to that level. Empty track clicks and dragging do not change the selection. Arrow keys and the default-level reset still work.
- Fast enables flowing particles at every reasoning level. Ultra adds slowly blending blue-purple light and particles, with faster movement when Fast is enabled.
- Opening the selector, changing the label, and toggling Fast now transition smoothly without rebuilding the popup.
- Remove the blue outline around the effort track for a cleaner appearance. Dots become visible on hover or focus, including inside the filled track.
- Honor reduced-motion preferences and stop animation work when the document is hidden or the selector closes.

The updated selector was checked in the browser preview and in Obsidian **1.14.4 on macOS**. Automated checks cover pointer and keyboard selection, cancelled gestures, scaled targets, Fast/Ultra behavior, reduced motion, and cleanup. These interface changes do not add reasoning levels or Fast support to models that do not provide them.

## Install or update

Download the three attached files: **`main.js`, `manifest.json`, and `styles.css`**. Close Obsidian and place them in `<vault>/<config-dir>/plugins/vault-codex/` (the default configuration directory is `.obsidian`). When updating, replace only these three files and preserve `data.json`, which contains your settings and conversations. GitHub's automatic Source code archives are not installable plugin builds.

Requires Obsidian desktop **1.13.7+** and a separately installed Codex executable with a working account/provider configuration.
