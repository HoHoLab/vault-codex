# Vault Codex 0.1.11

This patch resolves the blocking style-rule findings from the Obsidian Community review of 0.1.10. Fixed input height defaults and permission-menu alignment now live in CSS; the input still grows with its contents and popup positioning remains responsive.

## Requirements

- Obsidian **1.13.7 or newer**, desktop only.
- A separately installed Codex executable and a working account/provider configuration.
- Model services may require a ChatGPT subscription or paid API credits. The plugin itself is MIT-licensed and free.

## Install or update

Download `vault-codex-0.1.11.zip` and place its `vault-codex` folder in your vault's plugin directory. For an existing installation, close Obsidian and replace only `main.js`, `manifest.json`, and `styles.css`, preserving `data.json`.

The release also includes the three plugin files individually, a source archive, and SHA-256 checksums. Read the [README](https://github.com/HoHoLab/vault-codex#readme) for setup, permissions, network use, and optional dictation details.
