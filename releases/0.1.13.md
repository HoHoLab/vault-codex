# Vault Codex 0.1.13

This patch reduces GitHub release attachments to the three files consumed by Obsidian: `main.js`, `manifest.json`, and `styles.css`. It addresses the unsupported-extra-files review recommendation. Installation/source ZIPs and checksums remain available through local `npm run package` builds.

Plugin runtime source and styles are unchanged. Local Codex discovery and connection, file selection, Copy reply, language support, conversations, and preferences retain their existing behavior. Their capability-related review findings are not claimed as resolved.

## Install or update

See the [community listing](https://community.obsidian.md/plugins/vault-codex). Website publication does not by itself verify that the entry is searchable in every client's directory.

For manual installation, download all three attached files from this release. Close Obsidian, create `<vault>/<config-dir>/plugins/vault-codex/` (the default configuration directory is `.obsidian`), and place the files inside. For an update, replace only those three files and preserve `data.json`. GitHub's automatic Source code archives cannot be installed directly.

Requires Obsidian desktop **1.13.7+** and a separately installed Codex executable with a working account/provider configuration.
