# Vault Codex 0.1.12

This patch addresses the actionable code and CSS warnings from the Obsidian Community review without removing local Codex features.

- Add explicit types for protocol events, account responses, approvals, saved data, and transcription claims. Invalid JSON message envelopes now fail pending requests cleanly.
- Use the owning window for view and microphone timers, and explicit Node timers for process-level scheduling.
- Respect a custom vault configuration directory in assistant instructions.
- Preserve hidden controls, keyboard focus, accessible labels, and reduced motion while removing `!important`, `:has`, and `clip-path` from plugin CSS.
- Generate GitHub build provenance attestations for `main.js`, `manifest.json`, and `styles.css`.
- Add regression coverage for protocol compatibility, approvals, question inputs, Markdown rendering, custom configuration folders, and cancellation.

## Install or update

Open the [Obsidian community listing](https://community.obsidian.md/plugins/vault-codex), or check for updates in Obsidian's Community plugins settings. Requires Obsidian **1.13.7+**, desktop only, and a separately installed Codex executable with a working account/provider configuration.

For manual installation, use `vault-codex-0.1.12.zip`. For an existing installation, close Obsidian and replace only `main.js`, `manifest.json`, and `styles.css`, preserving `data.json`.

Direct filesystem access and local process execution remain necessary to discover and run Codex. Vault file enumeration supports note selection; clipboard writing supports Copy reply. These capabilities remain documented in the README. ZIP archives and checksums are included for manual installation and verification; Obsidian downloads only the three plugin assets.
