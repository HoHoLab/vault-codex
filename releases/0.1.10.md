# Vault Codex 0.1.10

Vault Codex brings the local Codex app server into an Obsidian sidebar, with streaming conversations, note and image references, file operations, approval cards, model selection, conversation history, and optional microphone dictation.

This is the first release prepared for the Obsidian Community directory under the ID `vault-codex`. Publication in the directory is a separate step; these assets also support manual installation.

## Requirements

- Obsidian **1.13.7 or newer**, desktop only.
- A separately installed Codex executable that supports `app-server --listen stdio://`.
- A working Codex account/provider configuration. Service subscriptions, usage charges, and quotas are separate from this free MIT-licensed plugin.
- The interface can follow Obsidian's language or use a language selected in settings. Windows and Linux have not been verified on real machines.

## Changes

- Support Obsidian 1.13.7 with native macOS settings and migration verification; build against the 1.13.1 public API definitions.
- Add ten interface languages with automatic Obsidian-language selection and English fallback.
- Add settings for send shortcuts, panel position, automatic scrolling, custom assistant preferences, and response detail.
- Preserve conversation drafts, attachments, and history across language changes and panel moves. Apply changed or cleared assistant preferences to existing conversations on their next send.
- Rename the plugin to **Vault Codex** and its ID to `vault-codex`.
- Add the MIT license and English/Chinese documentation, including data flow and permission disclosures.
- Align the connection client and user agent version with `manifest.json`.
- Add a compatible-version map, release validation, source and installation ZIPs, SHA-256 checksums, and automated draft releases.

## Install

Extract `vault-codex-0.1.10.zip` into your vault's plugin directory. The resulting folder must be `vault-codex` and contain `main.js`, `manifest.json`, and `styles.css`. Enable **Vault Codex** in Settings → Community plugins.

For directory installation, attach **`main.js`**, **`manifest.json`**, and **`styles.css`** individually to the GitHub release tagged **`0.1.10`**. A ZIP alone does not supply the files Obsidian downloads.

## Migrate from development builds

The old ID was `codex-for-obsidian`. Disable it and close Obsidian, back up its plugin directory, install `vault-codex`, and copy only the old `data.json` into the new plugin directory before reopening Obsidian. Keep that backup private: it contains conversation text and settings. Enable only one of the two plugins, and reopen the sidebar if necessary. See [RELEASING.md](https://github.com/HoHoLab/vault-codex/blob/main/RELEASING.md#release-specific-disclosures) for the complete steps.

## Data and permissions

Chat and attached content are sent through your local Codex process to its configured provider and tools. Conversations and settings are stored in the vault's plugin `data.json`; Codex also maintains its own local state outside the vault. Optional dictation uploads recorded audio to `https://chatgpt.com/backend-api/transcribe` using the local Codex ChatGPT authorization. This dictation integration depends on a non-public endpoint and may become unavailable. Full access permits command execution and file access outside the vault. Read the README before selecting that mode.
