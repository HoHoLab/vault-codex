# Vault Codex

在 Obsidian 侧栏使用本机 Codex，引用笔记与图片、查看文件操作与审批，并在笔记库中保留连续对话。

[English](README.md) · [更新记录](CHANGELOG.md) · [发布说明](RELEASING.md)

这是由 hoho 维护的独立第三方插件，采用 MIT 许可证，与 Obsidian 或 OpenAI 官方没有隶属关系。界面可跟随 Obsidian 语言，也可在插件设置中单独选择。

## 使用条件与费用

- **Obsidian 1.13.7 或更新的桌面版**。插件需要启动本地进程并使用 Node.js，因此不支持移动端。
- 本机另行安装支持 `codex app-server --listen stdio://` 的 Codex 可执行文件。插件不会自行安装或更新 Codex。
- 在 Codex 中配置可用的账号与模型服务。插件本身免费；所选服务可能需要 ChatGPT 订阅、API 余额或其他服务费用。模型可用性、额度与 Fast 模式的费用由服务和账号决定。
- 远程模型、登录及可选的语音转写需要联网。模型和工具请求沿用本机 Codex 的配置。

本次发布支持 **Obsidian 桌面版 1.13.7+**，使用 **1.13.1** 的公开接口定义进行构建，避免依赖更新版本的接口。已在 macOS 的 **1.13.7** 实机验证插件加载、设置页、语言切换、本机 Codex 连接，以及迁移后原有对话和设置的保留。Windows/Linux 尚未实机验证；Windows 需指定原生 `codex.exe`，不支持 `.cmd` 启动脚本。

## 安装

### 社区插件库

插件在 Obsidian Community 发布后，可在「设置 → 第三方插件 → 浏览」搜索 **Vault Codex** 并安装、启用。在正式发布前，请使用手动安装。

### 手动安装

1. 从本项目的 GitHub Release 下载 `vault-codex-<版本号>.zip`。带 `-source` 的 ZIP 是开发源码，不是可直接安装的成品。
2. 关闭 Obsidian，把 ZIP 中的 `vault-codex` 文件夹解压到笔记库的插件目录。默认是 `.obsidian/plugins/`；修改过配置目录时，使用你实际的目录。
3. 确认结构如下：

   ```text
   你的笔记库/.obsidian/plugins/vault-codex/
     main.js
     manifest.json
     styles.css
     LICENSE
     README.md
     README.zh-CN.md
     CHANGELOG.md
     RELEASING.md
   ```

4. 打开 Obsidian，在「设置 → 第三方插件」启用 **Vault Codex**。
5. 点击机器人图标，或运行命令「Vault Codex: 打开聊天面板」。
6. 点击「连接 Codex」。已有本机 Codex 登录状态时直接复用；否则在插件设置的「登录 ChatGPT」一项点击「在浏览器登录」。界面名称会随所选语言变化。

macOS 会检查 PATH、Homebrew、常见用户目录、NVM 和已安装的 Codex/ChatGPT 应用路径。找不到程序时，在插件设置的「Codex 可执行文件」填写完整文件路径，再重新连接。这里填写路径，不是整条命令。

## 使用方式

| 功能 | 操作 |
| --- | --- |
| 连续对话 | 默认 Enter 发送，Shift+Enter 换行；可在设置中更换发送快捷键，生成时点击停止按钮 |
| 引用笔记、选区与图片 | 用输入框左下角 `+` 选择库内文件，或选中文字后运行「将选中内容发送到 Codex」 |
| 模型与推理强度 | 点击模型/强度控件，选择 Codex 返回的模型并调整滑块；Fast 仅在模型提供相应档位时可用 |
| 查看操作 | 命令、文件修改、MCP、搜索状态在生成时展示；需要批准或回答时显示卡片 |
| 历史与导出 | 通过输入框上方控件和更多菜单新建、恢复、导出本插件创建的对话 |
| 背景信息用量 | 悬停或聚焦圆环查看上下文占用；尚无报告时显示不可用，不代表套餐剩余额度 |
| 查看过程 | 完成后点击用时控件回看已记录过程；回答支持 Markdown 与复制 |
| 麦克风听写 | 点击麦克风开始录音，结束后转写到草稿，检查后再发送 |

大于 250 KB 的文本笔记请引用选区，或让 Codex 按文件路径读取；图片输入需要模型支持。历史列表不导入桌面应用中的所有聊天。

## 偏好设置

设置页按通用、助手、连接与账户、高级分组，可调整界面语言、Enter 或 Ctrl/⌘+Enter 发送、右侧栏/左侧栏/主编辑区位置及自动滚动。Shift+Enter 始终换行；向上阅读时暂停自动跟随。

支持英语、简体中文、繁体中文、日语、韩语、德语、法语、西班牙语、俄语和葡萄牙语。语言默认跟随 Obsidian；未支持的语言或缺失译文回退到英语。切换语言保留草稿、附件与历史；移动面板也会保留其他对话的草稿。语音输入结束后才能移动面板。

自定义助手偏好与回复详略从本笔记库的后续请求起生效，保存在设置中并传给 Codex，可能随模型请求发送。界面语言不翻译已有聊天，也不强制模型采用同一种回复语言。

回复详略提供**默认、简洁、适中、详细**四档。默认沿用本机 Codex 配置，其他档位需要模型支持。修改或清空这两项助手偏好后，插件会在下一次发送前重新连接并恢复同一对话，让历史对话也采用新设置。

## 权限与笔记库外访问

当前笔记库是 Codex 的工作目录。权限参数交给本机 app-server 执行，实际约束取决于 Codex 版本与账号/组织政策。

- **请求批准（默认）**：使用 workspace-write 沙箱，把笔记库设为可写根目录，禁用沙箱命令的网络访问；需要额外权限时向你请求批准。Codex 还可以使用其允许的临时目录。
- **帮我批准**：保留同样的沙箱，把额外权限请求交给支持该功能的 Codex 自动审查，并非一律允许。
- **完全访问权限**：关闭操作批准与该文件系统沙箱，Codex 可以按当前系统账号的权限执行命令、使用网络、访问和修改笔记库外的文件。

旧版只读设置会保留，直到你主动选择其他模式。生成期间不能切换权限或模型。不支持的服务端交互会被拒绝，连接失败也不会自动降级为完全访问。

**为什么会访问库外文件：**插件需要检查程序安装路径来定位 Codex；Codex 使用库外的账号配置、会话记录和临时文件。Codex 沙箱并不意味着所有库外读取都被禁止，完全访问或另行批准的操作还可进行更广泛的文件访问。MCP 工具可能有自己的权限。Codex 通过文件系统修改笔记，不接入 Obsidian 编辑器的撤销历史。

## 数据、账号与联网说明

Vault Codex 没有自行运营的后端，不添加客户端统计或广告。代码公开在本仓库，主要数据流如下：

| 数据或操作 | 去向与用途 |
| --- | --- |
| 提问、选中文本、引用笔记/图片及任务读取的内容 | 交给本地 Codex；Codex 根据任务将必要内容发送至你配置的模型服务，例如 OpenAI，以及使用的工具。远程模型处理本地笔记仍然涉及上传内容。 |
| 登录 | 浏览器打开 Codex 返回的登录地址，认证及服务配置由 Codex 管理。 |
| MCP、搜索等工具 | 使用本机 Codex 配置中的服务。具体地址、权限和数据处理方式取决于已启用工具，不是插件固定的一组服务。 |
| 听写录音 | 结束录音后，使用本机 Codex 的 ChatGPT 授权，从 Obsidian 上传到 `https://chatgpt.com/backend-api/transcribe`。 |
| 对话、自定义助手偏好、界面设置、模型与权限选择、程序路径及会话引用 | 保存在 `<笔记库>/<配置目录>/plugins/vault-codex/data.json`。Codex 还会在库外保存自身记录；同步或备份笔记库时可能复制这些插件数据。 |

插件不持久保存 API Key、授权令牌或录音文件。转写所需授权通过本地 app-server 的 `getAuthStatus` 临时取得，仅发送至固定的 ChatGPT 转写地址，不写入插件错误或日志。卸载插件不会删除 Codex 自身记录，也不会撤回已经发给服务的数据。

使用 OpenAI 服务时可参阅 [OpenAI 隐私政策](https://openai.com/policies/privacy-policy/)；自定义服务商或 MCP 服务的数据政策需要按实际配置查阅。

## 可选的麦克风听写

需要本机 Codex 登录 **ChatGPT**，并允许 Obsidian/操作系统访问麦克风；API Key 登录不能复用这项服务。只有点击麦克风后才开始录音，音频暂存在内存，单段最长两分钟、最多 25 MB。

结束录音会上传并转写，结果追加到草稿；取消会丢弃录音。切换对话或关闭侧栏会释放麦克风并取消等待。已经上传的音频无法通过取消按钮撤回。

听写依赖**非公开的 ChatGPT 转写接口**，不是承诺稳定的公共第三方转写 API。账号、组织政策或 Codex/服务版本变化可能影响可用性；本机成功测试不能推广为所有 ChatGPT OAuth 令牌都支持转写。HTTP 401 时仅刷新授权一次，其他失败明确显示，不会切换到另一项付费服务；不可用时可使用系统听写。

## 当前限制与问题反馈

- 仅桌面端；Windows/Linux 尚未实机验证。
- Codex 协议版本存在差异，模型、强度与自动审查需要服务端支持。
- 不包含桌面应用的全部任务调度、云任务、插件管理或实时语音功能。
- 只管理本插件创建的对话，不同步桌面应用里的全部聊天。

可在本仓库的 **Issues** 页面报告问题，附插件、Obsidian、系统与 Codex 版本及复现步骤。提交日志或截图前移除私人笔记、账号标识与凭证。

## 开发与打包

使用受支持的 Node.js LTS、npm 和系统 `zip` 命令；CI 使用 Node.js 24。

```sh
npm ci
npm run check
npm run package
```

- `npm run dev`：监听源码并重新构建。
- `npm run check`：类型检查、构建、自动测试及发布元数据检查。
- `npm run package`：生成独立发布附件、安装包、源码包、发布说明和 SHA-256 校验文件，位于 `artifacts/releases/<版本号>/`。
- `npm run smoke`：可选的真实 Codex 集成验证，在 `artifacts/smoke-vault/` 操作隔离测试笔记库；会消耗模型额度，打包流程不自动运行。

发布步骤见 [RELEASING.md](RELEASING.md)。生成文件、依赖、测试笔记库和私人数据不进入公开源码包。
